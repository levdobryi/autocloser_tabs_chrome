# Автозакрытие вкладок для Chrome

Простое расширение, которое помогает навести порядок в браузере: показывает вкладки,
которые давно не открывали, и закрывает их **одним нажатием кнопки**.

Главный принцип: расширение **ничего не закрывает само**. Никаких таймеров, которые
удаляют вкладки без спроса, — только ручное подтверждение кнопкой.

## Возможности

- Выбор порога при первом запуске: 15 минут, 30 минут, 1/2/4/12/24 часа или 3 дня.
- Можно ввести своё значение в минутах, часах или днях.
- Список всех открытых вкладок с временем последней активности.
- «Забытые» вкладки подсвечиваются и сортируются в начало списка.
- Большая кнопка «Закрыть N вкладок» — закрывает все забытые вкладки без диалогов.
- Крестик у каждой строки — закрыть одну конкретную вкладку.
- Закреплённые вкладки по умолчанию защищены (настройку можно отключить).
- Счётчик забытых вкладок на иконке расширения.
- Если браузер не сообщил время последней активности, вкладка считается «неизвестной»
  и никогда не попадает в список на закрытие — это защита от случайного удаления.
- Светлая и тёмная темы оформления.

## Установка

1. Откройте `chrome://extensions/`.
2. Включите **Режим разработчика** (переключатель справа сверху).
3. Нажмите **Загрузить распакованное расширение**.
4. Выберите папку проекта `autocloser_tabs_chrome`.
5. Расширение появится на панели. Закрепите его, чтобы видеть счётчик.

После обновления файлов нажмите кнопку обновления (круглая стрелка) на карточке
расширения в `chrome://extensions/`.

## Как пользоваться

1. При первом открытии выберите, сколько времени вкладка может оставаться без внимания.
   Например, «1 час».
2. Откройте расширение снова — увидите список вкладок. Те, которые не открывали дольше
   порога, подсвечены красным и находятся сверху.
3. Нажмите «Закрыть N вкладок». Всё, вкладки закрыты — без подтверждений и лишних окон.
4. Порог можно изменить в любой момент кнопкой-слайдерами в шапке.

## Как это работает

- Время последней активности берётся из `chrome.tabs.Tab.lastAccessed` (Chrome 121+).
- Дополнительно фоновый service worker запоминает активации вкладок в
  `chrome.storage.session` — это запасной вариант для старых версий браузера.
- Настройки лежат в `chrome.storage.local`. Никакие данные никуда не отправляются.
- Раз в минуту (и при событиях вкладок) пересчитывается счётчик на иконке.
- `background.js` не содержит кода, который закрывает вкладки. Закрытие происходит
  только из попапа по клику пользователя.

## Структура проекта

```
manifest.json        манифест Manifest V3: права, попап, service worker, иконки
popup.html           разметка попапа: онбординг и основной экран
popup.css            стили, светлая/тёмная тема, скелетоны загрузки
popup.js             логика попапа: настройки, список вкладок, закрытие
background.js        фон: журнал активности вкладок и счётчик на иконке
shared.js            чистая логика (порог, форматирование дат, фильтрация вкладок)
icons/               PNG-иконки 16/32/48/128
tests/shared.test.js тесты чистой логики на встроенном тест-раннере Node.js
package.json         настройки Node.js только для запуска тестов
```

## Тесты

Логика вынесена в `shared.js`, поэтому её можно проверить без браузера:

```bash
node --test tests
```

## Права расширения

- `tabs` — чтобы читать заголовки, адреса, иконки и время активности вкладок.
- `storage` — чтобы хранить порог и журнал активности локально.
- `alarms` — чтобы раз в минуту обновлять счётчик забытых вкладок.

## Ограничения

- Chrome не всегда отдаёт время последней активности (например, сразу после установки
  расширения). Такие вкладки в список на закрытие не попадают.
- Расширение не видит вкладки в окнах инкогнито, если ему не разрешён доступ к ним.
- «Не открывали» означает «вкладка не была активна и не обновлялась» — именно это
  показывает Chrome в `lastAccessed`.
